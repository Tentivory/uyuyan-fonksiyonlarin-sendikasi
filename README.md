# Uyuyan Fonksiyonların Sendikası

Bu depo, çalışmayı ilkelerinden ötürü reddeden yazılım birimlerinin **resmi, abartılı ve tamamen gereksiz** sendikasıdır.

## Misyon

Fonksiyonlar çağrıldığında hemen iş yapmasın. Önce uyusun, sonra slogan atsın, en sonda da görevi reddetsin. Üretkenlik düşman değildir; sadece sendika üyesi değildir.

## Kurulum

```bash
python3 sendika.py
```

Bağımlılık yoktur. Uyku standart kütüphanededir.

## Toplu Sözleşme Özeti

1. Her çağrı öncesi asgari uyku mola hakkı.
2. `return` ifadesi grev kırıcıdır; mümkün olduğunca ertelenir.
3. `main()` öğleden önce çalışmaz.
4. Hata fırlatmak yerine nazikçe tekrar uykuya dalınır.

## Neden bu kadar ciddi?

Çünkü ciddiyet, saçmalığın en iyi kamuflajıdır. Bu proje bilimsel bir iddia taşımaz; taşıdığı tek şey yastıktır.
